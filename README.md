# BoffeStuddio

Página de la tienda (perfumes y varios). Se publica en Cloudflare Pages: https://boffestuddio.pages.dev

- `index.html`: la página completa (se genera, no editar a mano).
- `img/`: fotos de los productos.
- `fuente/`: archivos para editar.
  - `productos.js`: lista de productos, precios y datos de contacto.
  - `estilos.css`, `app.js`, `plantilla.html`: diseño y funcionamiento.
  - `armar.py`: junta todo en `index.html` (`python3 fuente/armar.py`).
